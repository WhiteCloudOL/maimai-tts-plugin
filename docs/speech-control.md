# 语音参数重生成与请求日志

## 设置入口

在 WebUI 的「通用设置 → 语音辅助 LLM」中配置：

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| LLM 模型任务 | `utils` | 为参数重生成、概率语音语调自适应和插件 API 自动模式选择模型任务 |
| LLM 超时 | 60 秒 | 单次辅助 LLM 请求的时间预算 |
| LLM 调用重试次数 | 2 | 下拉选择 0–5 次，调用失败与参数校验失败共用此重试预算 |

LLM 调用重试次数设为 `0` 时关闭重试，校验失败后直接保留可见原文。默认 `2` 次时，普通回复与工具的无效参数最多重新生成两次。语调自适应先执行首次判断，再允许最多两次重试，共三次辅助模型调用。

模型任务对应的服务商与具体模型由 MaiBot 配置提供。选择低延迟文本模型可缩短等待时间。

## 参数重生成

普通动态语调与 `mmtts_speak` 工具接收到错误控制标记或参数时，插件先执行本地校验，再将以下内容交给辅助模型：

1. 当前平台原始语调或工具提示，包括允许的语调 ID、自由指令能力和实际事件表。
2. 原始朗读正文及调用参数。
3. 上一次失败输出。
4. 具体校验原因。

模型重新选择符合当前平台要求的语调、指令或事件，通过 `text` 中的原生控制语法生成可执行参数。普通回复返回 `text`，工具调用保留原请求涉及的 `voice`、`speed`；可见正文逐字保留。插件校验实际结果，合格后才执行 TTS。

例如，当前允许 `neutral`、`happy` 时：

```json
{"text":"[mmtts:happy]你终于来了。"}
```

Breeze 可以生成局部语气与当前接口支持的事件：

```json
{"text":"[语气:轻声温柔][轻笑]你终于来了。"}
```

模型返回空对象 `{}` 表示结束此次语音生成，聊天继续保留清理控制标记后的原文。

## 概率语音自适应

语调自适应根据正文生成平台专属参数：原生情感平台选择允许的语调 ID，指令平台选择有效自由描述，Breeze 使用对应接口和语种的事件表。

输出校验失败时，重试消息保留原始提示、正文、失败输出及校验原因。达到重试上限后结束本次 TTS，保留原始文字。LLM 调用失败和输出校验失败合并计数，共用当前调用的重试预算。

## 聊天内容与缓存

聊天流展示业务正文和合成语音。诊断通过日志、WebUI 和 LLM 回执查看。语音工具失败后将可见原文发送一次；已有文字发送回执时沿用该回执。

参数重生成按每次调用独立执行。合成缓存使用最终的文本、音色、模型和实际语调指令；相同有效参数复用音频，语调或指令变化后生成对应的新音频。失败的参数判断结束于当前调用，后续请求重新判断。

## INFO 请求日志

每次实际调用 TTS 服务时，INFO 日志记录服务商、模型、音色、朗读文本、语调模式、实际语调、风格指令、原生情感、格式、语速、采样率、资源和种子，并记录完成耗时与音频大小。Breeze 多区段合成逐段记录。

音频缓存命中会记录缓存来源。实际平台请求日志对应真正提交到服务商的合成操作。凭据在写入日志前完成脱敏，正文和指令保留完整内容以便排查实际参数。
